<h1>🦶 Clínica Podológica – Proyecto Web</h1>

<h2>Sitio web moderno para una clínica podológica, con gestión de servicios, contacto rápido, y diseño responsivo.</h2>

🛠 Tecnologías utilizadas: </br>
* ⚡ Vue 3 + Composition API – Modularidad y lógica reactiva
* 💎 Tailwind CSS – Estilos modernos y responsivos
* 📦 Vite – Construcción rápida del proyecto
* 📂 Assets locales – Imágenes, íconos y recursos propios
* 📝 Funcionalidades principales
* 👣 Sección “Sobre la Clínica” – Historia y valores con animaciones
* 💼 Servicios – Lista interactiva de tratamientos y especialidades
* 🏆 Por qué elegirnos – Beneficios destacados y llamadas a la acción
* 📍 Contacto y ubicación – Formulario de contacto y mapa embebido
* 📅 Reserva de cita – Botón de CTA con animaciones y estados (enviando / enviado)
* 📊 Estadísticas de confianza – Satisfacción de clientes, pacientes atendidos, años de experiencia </br>


🚀 Instalación

Clona el proyecto y ejecuta localmente:

# Clonar repositorio
git clone https://github.com/TU_USUARIO/TU_REPO.git

# Entrar al proyecto
cd TU_REPO

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

El proyecto estará disponible en http://localhost:5173/.
